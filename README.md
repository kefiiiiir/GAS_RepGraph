# Проект GAS RepGraph

Прототип многопользовательской RPG от первого лица, созданный на Unreal Engine 5 с использованием собственной архитектуры системы способностей (GAS) и ориентированного на репликацию дизайна с помощью Replication Graph.

---

## Обзор

Этот проект демонстрирует модульную игровую структуру на основе GAS с упором на:

- Настройка персонажа на основе данных
- Корректность сетевой репликации
- Четкое разделение уровней игрового процесса (Персонаж / Состояние игрока / ASC)
- Расширяемая система способностей и атрибутов
- Многопользовательское взаимодействие от первого лица

Архитектура соответствует лучшим практикам Unreal Engine для масштабируемых многопользовательских игровых систем.


---

## Основные системы

### Система способностей в игровом процессе (GAS)

Проект полностью интегрирован с системой способностей Unreal Engine:

- Пользовательский компонент системы способностей (`UGASAbilitySystemComponent`)
- Наборы атрибутов, хранящиеся в PlayerState для сохранения
- Система предоставления способностей и пассивных навыков
- Инициализация атрибутов по умолчанию через игровые эффекты

Ключевые особенности:
- Активные способности (управляемые вводом)
- Пассивные способности (автоматически активируемые)
- Настройка классов на основе данных через DataAssets

---

### Архитектура персонажа

Разделение обязанностей:

- **Персонаж**

- Движение, ввод, камера, сетка

- Визуальное представление (руки FPS)

- **PlayerState**

- Владеет компонентом системы способностей

- Владеет набором атрибутов

- Сохраняется после возрождения

- **Компонент системы способностей**

- Управляет способностями

- Применяет игровые эффекты

- Обрабатывает Логика атрибутов

---

### Классы персонажей, управляемые данными

Настройка персонажа осуществляется с помощью:

- Ресурса данных `UCharacterClassInfo`
- `FCharacterClassDefaultInfo`

Поддерживает:
- Атрибуты по умолчанию для каждого класса
- Начальные активные способности
- Пассивные способности

Это позволяет быстро итерировать процесс без изменений в коде.

---

### Система ввода

Использует улучшенную систему ввода Unreal Engine:

- Движение (WASD / аналоговый ввод)
- Обзор (мышь / контроллер)
- Прыжок
- Расширяемое сопоставление ввода способностей (готово к использованию GAS)

---

### Сетевое взаимодействие / Репликация

Разработано для корректной работы в многопользовательском режиме:

- Инициализация GAS на **сервере (PossessedBy)**
- Инициализация GAS на **клиенте (OnRep_PlayerState)**
- PlayerState владеет данными, имеющими отношение к игровому процессу
- Оптимизированная частота репликации для повышения отзывчивости

---

## Ключевые классы

- `AGAS_RepGraphCharacter` – Персонаж игрока (движение + камера + ввод)
- `AGASPlayerState` – Постоянное состояние игрового процесса + владение GAS
- `UGASAbilitySystemComponent` – Расширенная логика GAS
- `UGASAttributeSet` – Игровой процесс Атрибуты
- `UCharacterClassInfo` – Конфигурация класса на основе данных
- `AGAS_RepGraphGameMode` – Правила игры на стороне сервера + доступ к данным класса
- `UGASAbilitySystemLibrary` – Вспомогательные утилиты Blueprint/C++

---

## Поток класса персонажа

1. Появление игрока
2. GameMode предоставляет данные класса
3. PlayerState владеет компонентами GAS
4. Персонаж инициализирует информацию об акторе GAS
5. Атрибуты и способности применяются из DataAsset
